## 🧑‍💻 About Me / 关于我

> 我是一名专注于**边缘计算**的架构师，信奉"把计算推到离用户最近的地方"。
> I'm an **Edge Computing Architect** who believes in pushing compute to the nearest point of presence.

- 🌐 深耕 Cloudflare Workers / Pages 生态，用 Serverless 构建全球低延迟服务
- ⚡ 痴迷于把 RTT 从三位数压到个位数——每一个毫秒都是对用户的尊重
- 🔒 Zero Trust 实践者——不信任任何网络，验证一切，加密一切
- 🧩 Composable 架构信徒——小模块、松耦合、自由组合，拒绝巨石应用
- 🎨 业余审美在线，坚信 CLI 工具也值得一个漂亮的 UI
- 📡 关注 QUIC / WebTransport / Wasm 等下一代传输与计算范式
- 🌏 坐标 Asia/Shanghai，活跃于 UTC+8 时区

> 部署在 Cloudflare Workers 边缘节点的专业级网络诊断工具。
> A professional network diagnostics tool running on Cloudflare Workers edge nodes.
> **实时监控 · 多维度测试 · 毫秒级响应 · 极光玻璃拟态设计 · 企业级安全防护**

**一句话**：5 分钟部署，零服务器成本，获得一个全球可用的网络质量监测站。

#### 🏗️ Architecture / 架构

```
┌─────────────────────────────────────────────────────────────┐
│                       User / Client                          │
│              (Browser · curl · websocat · CI)                │
└──────────────────────────┬──────────────────────────────────┘
                           │ HTTPS / WSS
                           ▼
┌─────────────────────────────────────────────────────────────┐
│               Cloudflare Edge (300+ PoPs)                    │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  _workers.js                                           │  │
│  │  ┌──────────┐  ┌────────┐  ┌─────────┐  ┌─────────┐  │  │
│  │  │  Rate    │→ │ Router │→ │ Handler │→ │Response │  │  │
│  │  │  Limiter │  │        │  │         │  │Builder  │  │  │
│  │  └──────────┘  └────────┘  └─────────┘  └─────────┘  │  │
│  │                                                        │  │
│  │  Bindings: KV (SPEED_HISTORY) · Secrets · Env Vars     │  │
```

#### ✨ Key Features / 核心能力

| 维度 | 能力 | 亮点 |
|:---|:---|:---|
| 🌊 网络质量 | 实时 RTT · 丢包率 · 抖动分级 · 连接评分 · DNS 延迟 · 多节点对比 | 每 2s 自动采样，Canvas 实时趋势图 |
| 🏎️ 性能测试 | 带宽测速 · CPU 基准 · 并发压力 · 流式吞吐 · WebSocket Ping | 多档位自适应，ops/ms 量化 |
| 🔐 协议安全 | TLS 版本 · 加密套件 · ECH · ALPN · HTTP/2/3 · IP 欺诈评分 | Early Hints 检测，Scamalytics 集成 |
| 🌍 地理追踪 | 边缘节点定位 · 客户端 IP 归属 · 距离计算 | ASN/运营商/坐标一屏展示 |
| 📊 数据持久 | 测速历史 (KV) · 用量统计面板 · Top-N API 调用 | 自动保存最近 5 条，可视化面板 |
| 🎨 前端体验 | 极光玻璃拟态 · 深色/浅色/自动 · 响应式 · 三语切换 | 30+ CSS 变量，backdrop-filter 磨砂 |
| 🛡️ 安全防护 | IP 限流 · 参数上限 · 域名白名单 · CORS 策略 | 60 req/min/IP，防滥用开箱即用 |

#### 🔌 API Endpoints / 接口一览

| 端点 | 方法 | 描述 |
|:---|:---:|:---|

#### ⚡ Quick Start / 快速体验

```bash
# 健康检查
curl https://your-worker.workers.dev/health

# 带宽测速 (100KB)
curl https://your-worker.workers.dev/speedtest?size=102400

# CPU 基准 (50 万次迭代)
curl https://your-worker.workers.dev/cpu-test?n=500000

# 协议检测
curl -sI https://your-worker.workers.dev/http2-test | head -5

# WebSocket 延迟
websocat wss://your-worker.workers.dev/ws-test

# 并发压力 (8 路 × 32KB)
curl "https://your-worker.workers.dev/concurrent-test?count=8&size=32768"
```

#### 🚀 Deploy / 部署方式

| 方式 | 适合场景 | 耗时 |

## 🔧 Environment Variables / 环境变量

| 变量 | 默认值 | 说明 |
|:---|:---:|:---|
| `MAX_REQUESTS` | 60 | 每 IP 每分钟最大请求数 |
| `MAX_CPU_REQUESTS` | 3 | 每 IP 每分钟 CPU 测试次数 |
| `ALLOWED_DOMAINS` | — | DNS 代理白名单（逗号分隔） |
| `SPEED_HISTORY` | — | KV 命名空间绑定 |

> ⚠️ 敏感配置请使用 `wrangler secret put <KEY>` 注入，不要硬编码。
