下图展示了 CF-workers-netdiag 在全球边缘节点中的工作流。

用户访问 ──► [⚡ Cloudflare Worker 边缘节点]
                          │

    │  └────┬─────┘  └────┬─────┘  └────┬─────┘  │
    │       │             │             │         │
    │       └─────────────┼─────────────┘         │

用户通过 HTTP/WebSocket 访问 Worker，Worker 并行向全球多个边缘节点发起测速，聚合后通过 WebSocket 推送至前端渲染。

一键部署 & 本地运行

想自己搭建一个？只需几步：

# 1. 克隆项目
git clone https://github.com/BlueDriftHK/CF-workers-netdiag.git
cd CF-workers-netdiag

# 2. 安装依赖
npm install

# 3. 本地开发（热更新）
npx wrangler dev

# 4. 部署到全球边缘（需 Cloudflare 账号）
npx wrangler login
npx wrangler publish

💡 部署后你会获得一个 *.workers.dev 域名，即刻拥有自己的全球延迟监控面板！
