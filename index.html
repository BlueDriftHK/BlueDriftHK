PersonalDrive

基于 Cloudflare Workers 的个人网盘 · R2 + KV + Durable Object 单文件部署 · 约 6500 行 · Apple / macOS Sonoma 风格前端

v5.1.2 R2 = DRIVEKV = STOREDO = DIR（可选） 在线体验 ↗ GitHub ↗

登录鉴权 + TOTP

管理员密码（带盐哈希）、7 天会话、可撤销会话列表、可选 TOTP 两步验证、IP 黑白名单与登录限频。

目录锁

目录可设独立密码，锁定目录内容需解锁访问；分享链路实时校验锁状态，锁定目录不可分享。

分享 / 上传链接

文件与目录分享（密码、TTL、访问次数），`/u/` 匿名上传链接，公开上传页可配 Turnstile 人机验证。

分片续传 + 秒传

分片上传与断点续传（失败任务存 localStorage），按 SHA-256 哈希秒传去重，内存拼装上限 50MB。

WebDAV

`/dav/` 端点可挂载到 Windows / macOS / 手机；rw 访问令牌认证，PUT 单文件上限 100MB，流式写入。

版本 / 回收站 / 备份

覆盖写入保留 5 个历史版本；删除进回收站可恢复；全量备份一键创建、下载、密码保护恢复。

NetSight Pro

单文件 Cloudflare Worker 网络诊断工具 · 灰度 HUD · 三语言（EN / 简体 / 繁體）· 全站诊断数据浏览器端实时计算渲染

4.1-security 单 WorkerKV 软依赖CSP(nonce)SSRF 防护 在线体验 ↗ GitHub ↗

实时 RTT 监控

每 2s 探测一次，绘制延迟趋势图，计算抖动、最低/最高 RTT 与丢包率、质量与稳定性等级。

测速 / 并发 / 流式

多档位上下行测速、4/6/8 路并发、分块流式吞吐、TTFB 分阶段拆解。

TLS / 指纹 / 协议

判定 HTTP/2·3 与 ALPN，展示 TLS 版本、加密套件、ECH 推断，以及 JA3 / JA4 指纹与 Bot 评分。

站点体检

审计任意站点 HTTP 安全响应头（HSTS / CSP / X-Frame-Options 等）与响应性能，有 SSRF 防护兜底。

WebRTC 泄漏检测

收集 ICE 候选，判断内网 / 公网 IP 是否经 WebRTC 泄露。

IP / 位置 / 风险

双栈 IP 获取、客户端地理位置与运营商、到边缘节点距离、代理 / VPN / 托管风险评分。

关于我

你好，我是 蓝漂（BlueDrift）。一名统计与大数据方向的在校学生，也是 Cloudflare Workers 生态的深度折腾玩家。业余时间喜欢把「想法」压缩成一个单文件 Worker，再亲手部署上线——追求开箱即用、零构建、单文件到底的工程风格。

主要兴趣集中在边缘计算、网络可观测性与自托管基础设施：自托管网盘、网络诊断工具、DNS 与组网实验、个人博客与开源项目。信奉「能跑就行，跑得漂亮更好」。
