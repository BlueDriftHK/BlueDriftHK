HTTP/3 vs HTTP/2

检测你当前连接实际使用的协议，并对比两代 HTTP 的核心差异。

HTTP/2
  • 基于 TCP，队头阻塞仍存在
  • 多路复用单一 TCP 连接
  • TLS 1.2/1.3 之上
  • 丢包会阻塞所有流
HTTP/3
  • 基于 QUIC (UDP)，无队头阻塞
  • 流级别独立，丢包互不影响
  • 内建 TLS 1.3，0-RTT 重连
  • 连接迁移（切网不断线）
